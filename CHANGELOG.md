# Changelog

## [1.1.0] - 2025-01-XX

### Добавлено

#### Whitelist/Blacklist таблиц
- Поддержка `ODATA_TABLES_WHITELIST` для ограничения доступа только к указанным таблицам
- Поддержка `ODATA_TABLES_BLACKLIST` для исключения определенных таблиц
- Валидация доступа во всех CRUD операциях
- Автоматическая фильтрация таблиц в метаданных

#### Swagger UI
- Интерактивная документация API доступна на `/api-docs`
- Автоматическая генерация документации из декораторов
- Опция `ENABLE_SWAGGER` для отключения в production
- Полное описание всех endpoints с примерами

#### Структурированное логирование
- Поддержка JSON формата логов через `LOG_FORMAT=json`
- Структурированные логи для интеграции с системами мониторинга
- Обратная совместимость с текстовым форматом
- Улучшенное логирование запросов и ответов

#### Оптимизация метаданных
- Метод `getAllTablesColumns()` - один запрос вместо N+1
- Кэширование структуры колонок таблиц
- Значительное ускорение генерации метаданных для больших баз данных

#### Валидация данных
- Автоматическая валидация данных перед вставкой/обновлением
- Проверка существования полей
- Проверка nullable полей
- Понятные сообщения об ошибках валидации

#### Поддержка Views
- Опция `ODATA_INCLUDE_VIEWS` для включения views в метаданные
- Views автоматически доступны через API при включении опции
- Правильная обработка views в метаданных OData

#### Тесты
- Unit тесты для `ODataParserService`
- Unit тесты для `DatabaseService`
- E2E тесты для основных endpoints
- Базовая структура для расширения покрытия тестами

### Изменено

- Обновлен `env.example` с новыми опциями конфигурации
- Улучшена обработка ошибок в `ODataService`
- Оптимизированы запросы к базе данных для метаданных
- Улучшена документация в README.md

### Исправлено

- Исправлена проблема с контекстом `this` в LoggingMiddleware при использовании ConfigService
- Улучшена обработка ошибок при валидации данных

### Технические детали

- Добавлены зависимости: `@nestjs/swagger`, `swagger-ui-express`
- Обновлены импорты в контроллерах для поддержки Swagger
- Добавлен кэш для колонок таблиц
- Расширена функциональность `ConfigService` для новых опций

## [1.0.0] - 2025-01-XX

### Добавлено

- Базовый функционал OData API
- Поддержка CRUD операций
- OData параметры ($filter, $orderby, $top, $skip, $select, $count)
- XML метаданные в формате EDMX
- Детальное логирование запросов
- CORS поддержка
- Excel совместимость
