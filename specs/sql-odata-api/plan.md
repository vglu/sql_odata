# План реализации SQL OData REST API

## Обзор архитектуры

Приложение построено по модульной архитектуре NestJS с разделением на следующие модули:
- **Database Module** - управление подключениями к MS SQL Server
- **OData Module** - реализация OData протокола
- **Root Module** - обработка корневых запросов (для Excel совместимости)
- **Common** - общие middleware и interceptors

## Архитектурные решения

### Использование Connection Pool

Connection pool управляется автоматически через mssql драйвер:
- Максимум 10 соединений
- Минимум 0 соединений
- Timeout простоя: 30 секунд

### Безопасность SQL запросов

1. **Валидация имен таблиц**: Регулярное выражение `/^[a-zA-Z_][a-zA-Z0-9_]*$/`
2. **Параметризованные запросы**: Все значения передаются через параметры
3. **Экранирование имен полей**: Все имена оборачиваются в квадратные скобки `[name]`

### Обработка типов данных

Типы данных преобразуются при генерации метаданных, но исходные SQL типы сохраняются для корректной работы с базой данных.

### Пагинация

Используется SQL Server `OFFSET ... FETCH NEXT ...` синтаксис для эффективной пагинации больших результатов.
