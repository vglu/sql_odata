# SQL OData REST API - Спецификация

Этот каталог содержит полную спецификацию проекта SQL OData REST API в формате [Spec-Kit](https://github.com/github/spec-kit).

## Структура документации

### Основные документы

- **[spec.md](./spec.md)** - Полная спецификация проекта с пользовательскими историями и техническими требованиями
- **[plan.md](./plan.md)** - Детальный план реализации с описанием всех этапов разработки
- **[data-model.md](./data-model.md)** - Описание модели данных и преобразования типов
- **[quickstart.md](./quickstart.md)** - Руководство по быстрому старту и примеры использования

### Контракты API

- **[contracts/api-spec.json](./contracts/api-spec.json)** - OpenAPI 3.0 спецификация всех endpoints

## Статус реализации

✅ **Завершено:**
- Базовая инфраструктура проекта
- Модуль работы с базой данных
- Парсер OData запросов
- OData сервис с полной поддержкой CRUD операций
- OData контроллер
- Корневой контроллер для Excel совместимости
- OData Interceptor
- Детальное логирование
- XML метаданные в формате EDMX

🔄 **В процессе:**
- Production оптимизации
- Health check endpoints

📋 **Запланировано:**
- Rate limiting
- Аутентификация и авторизация
- Поддержка views
- Определение первичных ключей из метаданных
- Кэширование метаданных

## Как использовать эту документацию

1. **Для новых разработчиков**: Начните с [quickstart.md](./quickstart.md) для быстрого старта
2. **Для архитекторов**: Изучите [spec.md](./spec.md) и [data-model.md](./data-model.md)
3. **Для разработки**: Следуйте [plan.md](./plan.md) для понимания архитектуры
4. **Для интеграции**: Используйте [contracts/api-spec.json](./contracts/api-spec.json) для генерации клиентов

## Связь с кодом

Все документы синхронизированы с текущей реализацией в директории `src/`:
- `src/database/` - соответствует разделу Database Module в plan.md
- `src/odata/` - соответствует разделу OData Module в plan.md
- `src/common/` - общие компоненты (logging, interceptors)
- `src/root/` - корневой контроллер для Excel совместимости

## Обновление документации

При внесении изменений в код:
1. Обновите соответствующие разделы в spec.md или plan.md
2. Обновите api-spec.json если изменяются endpoints
3. Обновите quickstart.md если изменяются примеры использования
