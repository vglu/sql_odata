# Roadmap - План развития проекта

## Версия 1.1 (Ближайший релиз)

### Критичные улучшения

- [ ] **Определение реальных первичных ключей**
  - Запрос к INFORMATION_SCHEMA.KEY_COLUMN_USAGE
  - Поддержка составных ключей в операциях GET/PUT/PATCH/DELETE
  - Обновление метаданных EDMX с правильными Key элементами

- [ ] **Кэширование метаданных**
  - In-memory кэш с TTL (5 минут по умолчанию)
  - Конфигурируемый TTL через переменную окружения
  - Метод для ручной инвалидации кэша

- [ ] **Улучшенная обработка ошибок БД**
  - Специализированные исключения для разных типов SQL ошибок
  - Понятные сообщения об ошибках для пользователя
  - Логирование детальной информации об ошибках

- [ ] **Rate Limiting**
  - Базовая защита от злоупотреблений
  - Настраиваемые лимиты через конфигурацию
  - Разные лимиты для разных endpoints

## Версия 1.2

### Производительность

- [ ] **Оптимизация запросов метаданных**
  - Один запрос вместо N+1 запросов
  - Кэширование структуры таблиц

- [ ] **Health Check endpoints**
  - `/health` - общее состояние
  - `/health/db` - состояние подключения к БД
  - `/health/ready` - готовность к обслуживанию запросов

- [ ] **Connection Pool мониторинг**
  - Метрики пула соединений в health check
  - Логирование состояния пула при проблемах

### Безопасность

- [ ] **Whitelist/Blacklist таблиц**
  - Конфигурация через переменные окружения
  - Поддержка regex паттернов

- [ ] **Валидация данных**
  - Проверка типов данных перед вставкой
  - Проверка nullable полей
  - Проверка максимальной длины строк

## Версия 1.3

### Функциональность

- [ ] **Поддержка Views**
  - Опциональное включение через конфигурацию
  - Отдельная обработка views в метаданных

- [ ] **Расширенные OData функции**
  - substringof, indexof, substring
  - year, month, day для дат
  - round, floor, ceiling для чисел

- [ ] **Поддержка $search**
  - Полнотекстовый поиск по нескольким полям
  - Интеграция с SQL Server Full-Text Search (если доступен)

### Мониторинг

- [ ] **Структурированное логирование**
  - JSON формат для интеграции с системами мониторинга
  - Конфигурируемый формат (JSON/текстовый)

- [ ] **Метрики Prometheus**
  - Счетчики запросов
  - Метрики времени выполнения
  - Метрики ошибок
  - Метрики пула соединений

## Версия 2.0 (Долгосрочные цели)

### Расширенная функциональность OData

- [ ] **Поддержка $expand**
  - Определение foreign keys
  - Навигационные свойства в метаданных
  - Поддержка вложенных expands

- [ ] **Поддержка $batch**
  - Batch endpoint `/api/$batch`
  - Обработка множественных операций в одной транзакции
  - Atomic batch операции

- [ ] **Actions и Functions**
  - Custom actions для бизнес-логики
  - Custom functions для вычислений

### Производительность и масштабируемость

- [ ] **Read Replicas**
  - Поддержка чтения из реплик
  - Балансировка нагрузки запросов

- [ ] **Query result caching**
  - Кэширование результатов частых запросов
  - Redis интеграция для распределенного кэша

- [ ] **Асинхронная обработка**
  - Фоновая обработка больших запросов
  - Webhook уведомления о готовности

### Безопасность

- [ ] **Аутентификация и авторизация**
  - JWT токены
  - OAuth2 интеграция
  - Роли и права доступа к таблицам

- [ ] **Audit Logging**
  - Логирование всех операций изменения данных
  - Хранение истории изменений
  - Атрибуция изменений к пользователям

- [ ] **Data masking**
  - Автоматическое скрытие чувствительных данных
  - Конфигурация через атрибуты в метаданных
